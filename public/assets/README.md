# Asset Directory

Place runtime-loaded assets for the Nature Hall project here. Files under `public/assets` are served by Vite at `/assets/...` and copied into production builds.

Suggested folders:

- `characters/` for player and visitor sprites.
- `animals/` for animal NPC sprites and portraits.
- `maps/` and `tilesets/` for hall layouts and terrain tiles.
- `audio/` for ambient, UI, and animal sounds.
- `effects/` for particles, light masks, and other visual effect textures.
